# 查料号（惠而浦物料多表查询）

按料号综合查询惠而浦 PMC 多张报表，汇总某个物料的库存、送货、报检、未制单量、可发布量、回货未分配量、请购数量。

## 触发词

查料号

## 用法

- "查料号 ST1TN40100SE-"
- "帮我查料号 70C012345"
- "查料号 ST1TN40100SE- 看下这个料"

## 数据源目录

`E:\OneDrive\桌面\桌面临时文件\PMC小工具\回货引用文件\加载文件\`（文件名固定）

- `库存报表.xlsx`（表头在第2行）
- `送货单查询.xlsx`
- `送货通知查询.xlsx`
- `采购订单未结量物料汇总查询.xlsx`
- `回货计划发放.xlsx`
- `请购单查询.xlsx`

> 若目标料号在 `回货计划发放.xlsx` / `请购单查询.xlsx` 中无数据，输出 0 即可；不要报错终止。

## 查询逻辑

运行 `E:/SKILLS/.venv/Scripts/python.exe scripts/query.py 料号`（或 `node scripts/run.js 料号`，二者等价），脚本输出 JSON 汇总，最终按以下格式整理成表格回复。

### 1. 库存（库存报表.xlsx，区分供应商，按货位分多行）

- 筛选：`物料`=料号，`组织`=**M03**，`仓库编码`=**WL301**
- `货位`列格式为 `供应商编码/供应商名称WL`（如 `S1938/桐城宜春WL`）
- 拆出资货位，逐行展示：货位、供应商编码、供应商名称、库存数量

### 2. 送货单（送货单查询.xlsx，区分供应商，按供应商分多行）

按 `供应商编码` 归组（与库存货位中的供应商编码为同一供应商判断）：
- **未接收+未报检**：`是否接收`=未接收 且 `是否报检`=未报检 且 `物料编码`=料号 → 累加 `送货数量`
- **未接收+已报检**：`是否接收`=未接收 且 `是否报检`=已报检 且 `物料编码`=料号 → 累加 `报检数量`

### 3. 未制单量（送货通知查询.xlsx，区分供应商）

- `物料编码`=料号，按 `供应商编码`/`供应商名称` 区分，累加 `未制单量` 列

### 4. 剩余可发布量（采购订单未结量物料汇总查询.xlsx，区分供应商）

- `物料编码`=料号，按 `供应商编码`/`供应商名称` 区分，累加 `剩余可发布送货通知总量` 列

### 5. 回货未分配量（回货计划发放.xlsx，**不分供应商**）

- `物料编码`=料号
- 按 `可下发送货通知`（是/否）分行：
  - 可下发送货通知=**否** → 累加 `未分配量`
  - 可下发送货通知=**是** → 累加 `未分配量`

### 6. 请购数量（请购单查询.xlsx，**不分供应商**）

- `物料编码`=料号 且 `行状态`=**下达** → 累加 `请购单总数量`

### 7. 物料名称获取

- 运行 `E:/SKILLS/.venv/Scripts/python.exe scripts/get_mat_names.py 料号1 [料号2] ...`
- 输出 JSON `{料号: 物料名称, ...}`
- 数据源优先级：请购单查询.xlsx(col[14]) > 采购订单未结量(col[5]) > 送货单查询 > 库存报表
- 未找到返回空字符串
- **名称清洗规则**：`get_mat_names.py` 返回的名称含 `;` 分隔多段和 `\` 分隔子路径，取第一个 `;` 前段落作为主名称（如 `保护膜\LDPE\225mm*200m\856，956\` → `保护膜`）

## 输出格式（最终固化）

详见 `references/output-format-spec.md` 中的详细规范。

用一张横表回复，从左到右列：

`料号 | 货位 | 供应商编码/名称 | WL301 数量 | 车间库存 | 送货单 | 已报检 | 送货通知单 | 采购订单 | 回货计划否 | 回货计划是 | 请购单`

（说明：供应商编码与供应商名称合并在同一单元格，格式 `Sxxxx/供应商名称`；货位本身已含 WL301 库存的供应商短名称）

**组织规则：**

1. **以货位为行基准**（库存按货位分行，一个货位 = 一家供应商；同一供应商若有多货位则各占一行）。
2. 供应商相关列（**WL301数量** / 送货单 / 已报检 / 送货通知单 / 采购订单）按供应商编码对到各自行并逐行填值；有多个供应商/货位则分多行。“供应商编码/名称”列为 `Sxxxx/供应商名称` 合并展示（名称取该供应商对应全称，如送货/采购订单表里的供应商名称）。
3. **车间库存 / 回货计划否 / 回货计划是 / 请购单** 四列**不区分供应商**（全料号合计值），只在**合计行**显示，供应商行为空。车间库存 = 库存报表组织中 M03、库位∈{Y0001,Y0002,Y0003} 的全部库存合计。
4. 表格最下方 **合计行**：汇总所有列数值；车间库存/回货计划否/是、请购单四列的合计值即全料号值。

|---|---|:---:|---:|---:|---:|---:|---:|---:|:---:|:---:|:---:|
| ST1TN40100SE- | S1137/余姚自攻WL | S1137/余姚市自攻螺钉厂 | 8000 | | 0 | 0 | 0 | 42000 | | | |
| ST1TN40100SE- | S2051/上海艾伦WL | S2051/南通振群电子有限公司S | 8000 | | 0 | 2000 | 0 | 47248 | | | |
| **合计** | | | 16000 | **X** | 0 | 2000 | 0 | 89248 | **0** | **0** | **0** |

> 纯文本回复即可，无需生成 Excel/CSV/文本文件。用 Markdown 表格输出。
