# Inventory Daily Report Generator

**Description:** 自动生成成品库存日报。触发词：产销存报表。自动执行 VBA 宏刷新 Excel 数据，从"汇总"Sheet 提取关键指标，生成格式化日报摘要。

**Steps:**
1. 检查当前日期和时间（使用 `date` 命令）
2. 定位到成品库存 Excel 文件路径
3. 执行 VBA 宏刷新数据：打开 Excel → 运行"RefreshData"宏 → 等待完成
4. 从"汇总"Sheet 提取关键指标：总库存、已发货、待发货、安全水位、异常 SKU
5. 生成日报摘要报告，包含日期、关键指标表格、异常项列表及建议
6. 将报告保存到指定目录（如 C:\Users\qudin\Documents\Inventory_Daily_YYYYMMDD.xlsx）
7. 输出报告内容到终端供用户查看

**Verification:**
- 确认 Excel 文件已打开且宏执行成功
- 验证日报包含所有关键指标
- 检查异常项列表是否准确
- 确保报告文件保存成功并可正常打开

**Pitfalls:**
- **自动筛选未清除 → 期初库存/装柜数量变成上一班的旧数（已修复，最易误判）**：「数据整理」第 3 行合计用 `SUBTOTAL(9,...)`，只统计未被筛选隐藏的行。若工作簿保存时 AutoFilterMode=True（约 300 行被隐藏），SUBTOTAL 只算可见的 3 行 → 「汇总」的期初库存变成几百/几千台、装柜数量也偏小，而「当前库存」来自透视表所以**仍然正确**——这种"部分对部分错"最难发现。2026-10-24 实例：脚本输出期初库存 1,924（实为 29,673）、装柜 1,332（实为 32,403）。**修复：脚本在跑宏前显式 `ds.AutoFilterMode = False`**；诊断方法：`ds.AutoFilterMode` + `ds.Rows(r).Hidden` 计数，非 0 即为异常。
- **判断数据是否真刷新**：读「数据整理」Sheet 的每日矩阵——R 列起每 4 列一天（下线/出库/库存/折算面积），数据行 5~306。找最后一个有下线或出库值的日期，应 ≥ 今天-1。最新几天为 #N/A（COM 读出来是 -2146826246）即说明宏没跑或数据源未更新。**注意**：不要用第 3 行当判据，它是 SUBTOTAL，受筛选影响会假性为 0。脚本 v1.0.3 起内置此校验（Step 2b）。
- **加载项缺失会导致数据静默过期**：脚本依赖 `E:/SKILLS/inventory_daily/data/代码库.xlam` 提供「产量出货更新」宏。该文件丢失时宏报错（"无法运行…宏"），但脚本仍会照常出报告——用的是上次保存的旧数据。有效副本在 `E:/OneDrive/工作/9、VBA程序/回货引用文件/代码库/代码库.xlam`，复制回 data 目录即可恢复。
- `excel.SecurityLevel = 0` 在新版 Excel 上抛异常，不影响流程。
- 脚本用 DispatchEx 开独立 Excel 实例，异常退出会残留 EXCEL.EXE 并锁住输出文件（报 Permission denied）；结束该进程后重跑。
- **同日重复运行会产生 `成品库存YYYY-MM-DD_1.xlsx`、`_2` 等副本**（SaveAs 前做了存在性检查）。需要唯一报告时先清理同日的旧副本。
